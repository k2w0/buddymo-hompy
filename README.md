# 버디버디 미니홈피 (모바일용)

웹용 미니홈피(`buddybudddy-home`)를 복사해서 휴대폰 화면에 맞춘 버전입니다.
데이터베이스와 로그인은 웹용과 같아서, 어느 쪽에서 쓴 글이든 양쪽에서 똑같이 보입니다.

- 주소: `https://k2w0.github.io/buddymo-hompy/?uid={아이디}`
- 메뉴 탭은 위쪽 가로 줄, 프로필 칸과 내용은 위아래로 쌓입니다.
- 카테고리 수정/삭제는 **길게 누르기**(0.5초)로 엽니다.
- 휴대폰용 화면 조정은 `index.html`의 "모바일용 화면" 스타일 블록에 모여 있습니다.
- 기능을 고칠 때는 웹용 `index.html`도 같이 고쳐 주세요. (데이터 구조는 메신저 저장소의 `DATA_STRUCTURE.md`)
